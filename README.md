# K-Roof 차열 시뮬레이터 (OASIS 컨테이너 차열 지붕)

공사현장 **컨테이너 휴게실(6.0 × 3.0 × 2.8 m, 지붕 1.2T 강판)** 지붕에 얹는 차열 지붕 설계안 **A·B·C·C′안**의 열성능과 설치·해체 방식을 3D로 비교하는 웹 시뮬레이터입니다.

**▶ 바로 체험: https://dbdnjstjr32-oss.github.io/kroof-sim/**

설치 없이 브라우저에서 동작합니다(PC·iPad·휴대폰). WebGL을 지원하는 최신 브라우저가 필요합니다.

## 설계안

| | 설계안 | 구성 | 공기층 | 설치 방식 |
|---|---|---|---|---|
| A안 | 기존 컨테이너 (기준 모델) | 차열패널 없이 기존 1.2T 지붕 강판만 적용 (흡수율 0.70 · 방사율 0.90) | 없음 | — |
| B안 | ACP 밀착형 천공 고정 | 백색 고반사 ACP 4T(상부 반사율 0.89 · 하부 방사율 0.12)를 지붕에 직접 밀착하고, 방수 직결피스 + EPDM 고무 와셔로 패널과 기존 지붕 강판을 관통 체결 | 0 mm (직접 접촉) | 천공 고정 · 패널 재사용 가능, 해체 후 천공부 보수 필요 |
| C안 | ACP 차열 이중지붕 | ACP 4T 모듈 12개 + 아연도금 크로스바 5개·레벨러/고무패드, 드로우 래치, 크로스바 끝단 라쳇 스트랩·J후크 | 110 mm (폭 방향 4통로 자연환기) | 무천공 모듈식 탈부착 |
| C′안 | 갈바륨 차열 이중지붕 (경제성 개선) | 갈바륨 골강판 0.5T(C-76) 12모듈, 백색 차열도료(상부 반사율 0.75 · 하부 방사율 0.28), M8 나비볼트, 라쳇 스트랩·C형 클램프 | 140 mm (폭 방향 자연환기) | 무천공 모듈식 탈부착 |

## 최근 변경 사항 (2026-11-25)

- **B안 천공 고정 방식:** 방수 직결피스(EPDM 와셔) 96개를 패널당 8개씩 배치하고, 피스가 ACP 패널과 기존 지붕 강판을 관통하도록 모델링했습니다. 설치(지붕 노출 → 패널 배치 → 피스 체결 → 완료)와 해체(피스 제거 → 패널 분리 → 천공 흔적 잔존 → 방수·보수 필요 표시) 애니메이션을 추가했고, "상세" 시점에서 체결부 단면 개념도(피스 머리 · EPDM 와셔 · ACP 4T · 지붕 강판 1.2T)를 함께 보여줍니다.
- **B안 정보 표시:** 개요에 "밀착형 천공 고정 방식" 특징 6가지를, 사양 비교표에 기존 지붕 천공 · 해체 후 지붕 상태 · 패널 재사용 행을 추가해 C안·C′안의 무천공 방식과 비교할 수 있습니다.
- **C′안 표면 물성 조절:** 상부 태양광 반사율(흡수율 = 1 − 반사율 자동 연동)과 하부 장파 방사율을 직접 조절하거나 후보 조건(기존 + 후보 1~6)을 고를 수 있고, 기존 값으로 복원할 수 있습니다. 값을 바꾸면 지표·그래프·비교표가 다시 계산되고, 기존 C′안 대비 변화가 함께 표시됩니다.
- **C′안 민감도 분석표:** 후보 6종 결과를 기존 C′안 대비 변화와 함께 한 표로 비교합니다(B안·C안 참고 행 포함, CSV 저장에도 포함).
- **열해석 조건은 유지:** B안 물성값·공기층 0 mm·밀착 열전달 조건은 그대로이고, 피스에 의한 국부 열교는 제외했습니다.

## 할 수 있는 것

- **열해석:** 지역·날짜·시각별 태양 위치와 청천 일사량을 바탕으로 1차원 과도 열해석(5절점, 60초 간격, 48시간 안정화 + 24시간 출력)을 수행해 지붕 강판 하면 온도, 실내 온도, 일일 지붕 열유입량, 일일 냉방부하(냉방 08:00~18:00)를 계산합니다. 냉방 OFF·ON 결과를 동시에 산출합니다.
- **결과 비교:** 핵심 성능 지표 4종(A안 대비 변화), 24시간 온도 그래프(강판 하면·실내·통합, 냉방 OFF/ON 전환), 설계안별 최종 비교표, 사양·구조 비교표, C′안 민감도 분석표
- **3D 보기:** 단일 설계안 / 4동 나란히 비교, 원근·단면·상부·공기층·상세·현장 시점, 지붕 강판 온도 열지도, 공기층 기류, 태양광선, 부재 라벨, 태양궤적, 분해도
- **설치·해체:** 설계안별 단계별 설치·해체 애니메이션과 조립 완료 상태 복원 (B안: 피스 체결·제거와 천공 흔적, C안·C′안: 무천공 모듈 분리·재사용)

## 바꿀 수 있는 값

| 영역 | 항목 |
|---|---|
| 설계 | 설계안 선택(A·B·C·C′), 단일 / 4동 비교 |
| C′안 표면 물성 | 상부 태양광 반사율 0.50~0.95(흡수율 자동), 하부 장파 방사율 0.05~0.90, 후보 조건 7종, 기존 값 복원 |
| 시간 · 장소 | 5개 도시(서울·대전·광주·부산·제주) 또는 위도·경도·표준시 직접 입력, 월·일, 시각, 재생 속도 |

| 단열 · 냉방 | 지붕 단열재 0 / 50 mm, 냉방 가동(08:00~18:00), 냉방 설정온도 20~30 °C |

| 시나리오 | 이름으로 저장·불러오기(브라우저 저장), **링크로 설정 공유**, 설정 초기화, 비교표 CSV 저장 |

컨테이너 규격과 A·B·C안 물성값, C′안의 나머지 물성값(상부 장파 방사율 0.88, 갈바륨 0.5T 두께·열전도율·밀도·비열, 공기층 140 mm), 벽체 U = 1.0 W/㎡·K, 침기 0.5 ACH 등 실내 조건은 요청 자료 기준으로 고정되어 있습니다. 공유 링크의 값은 모두 허용 범위로 제한되어, 직접 고친 링크로도 계산이 깨지지 않습니다.

## 주의

- 본 시뮬레이션은 동일한 대표 여름 조건에서 설계안의 **상대적 열성능을 비교**하기 위한 1차원 과도 열수지 해석입니다. 열물성·대류·환기 계수는 시뮬레이션용 가정값이며, 상세 경제성 분석과 정밀 구조 안전성(풍하중 안전율·한계풍속) 검토는 범위에서 제외했습니다.
- 냉방부하는 냉방기 소비전력이 아니라 실내 설정온도를 유지하기 위해 제거해야 하는 열에너지량(kWh)입니다.
- B안 직결피스의 규격·수량·체결 간격은 확정되지 않았으며, 구조·방수 성능이 검증된 시공 상세가 아닌 **시각적 개념 표현**입니다(전체 화면에서 보이도록 피스 크기를 약간 키워 표현).
- 보강재·크로스바 열용량과 볼트·피스·스트랩·클램프 등 체결 부재의 개별 열전달(열교)은 열해석에서 제외합니다.
- C′안 후보 물성값은 최종 확정값이 아닌 **민감도 분석용**입니다. 결과 확인 후 실제 적용 가능한 차열도료 및 저방사 재료를 조사해 최종 값을 선정할 예정입니다.
- 앱 안의 「해석 조건 및 단순화 가정」에서 전체 가정 목록을 확인할 수 있습니다.

## 로컬 실행 · 개발

```bash
npm install
npm run dev      # http://localhost:8780/?force
npm test         # 물리 · 사용자 설정 · UI 검증 + 3D 모듈 통합 스모크 테스트
npm run build    # dist/ (GitHub Pages용 정적 사이트)
```

개발 서버는 `tools/.ready` 파일이 있을 때만 앱을 보여주고, 없으면 "빌드 중" 화면을 띄웁니다(이 파일은 저장소에 포함되지 않음). 주소 끝에 `?force`를 붙이거나 빈 `tools/.ready` 파일을 만들면 바로 앱이 열립니다.

`main` 브랜치에 푸시하면 GitHub Actions가 테스트 → 빌드 → Pages 배포를 자동으로 실행합니다.

구성: three.js 0.160 (ES 모듈, 빌드 도구 없음), Chart.js 4.4.
