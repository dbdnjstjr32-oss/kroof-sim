# K-Roof 차열 시뮬레이터

공사현장 **컨테이너 휴게실(3×6 m, 지붕 1.2T 강판)** 지붕에 얹는 차열 구조 설계안 **A–E**를 3D로 비교하는 웹 시뮬레이터입니다.

**▶ 바로 체험: https://dbdnjstjr32-oss.github.io/kroof-sim/**

설치 없이 브라우저에서 동작합니다(PC·iPad·휴대폰). WebGL을 지원하는 최신 브라우저가 필요합니다.

## 설계안

| | 설계안 | 핵심 | 공기층 |
|---|---|---|---|
| A | 비계 캐노피형 | 비계 강관 + 직교 클램프 프레임 위 Al 골판(백색/은박) | 0.5–1 m, 완전 개방 |
| B | 태양광 레일형 | Al 레일 + 스탠드오프, 프레임 반사 패널, 미드/엔드 클램프 | 8–10 cm |
| C | 크로스바·라쳇 스트랩형 | ㄷ자 브래킷 + 크로스바, 반사 골판, 라쳇 스트랩 → 인양고리 | 8–10 cm |
| D | 타프·차광막형 | 폴 6본 + 알루미늄 차광망(알루미넷), 번지볼 | 0.7–1 m, 망 통풍 |
| E | 다리 달린 인터로킹 패널형 | 다리 일체형 패널을 맞물려 한 판처럼, 캠레버 고정 | 8–10 cm |

## 할 수 있는 것

- **태양·열:** 지역·날짜·시각별 실제 태양 위치와 청천 일사량 → 설계안 형상으로 지붕 그늘을 레이캐스팅 → 열 모델로 지붕 온도 열지도, 24시간 온도, 지붕 유입열, 냉방 전력량
- **풍하중:** 순간풍속별 하중 경로(부재별 용량·수요)와 안전율, 한계풍속, 안전율 < 1이면 이탈 애니메이션
- **보기:** 도면 같은 단면 보기, 분해도, 단계별 설치 애니메이션, 6동(기존 + A–E) 나란히 비교, 공기층 기류·태양광선 표시

## 주의

- 치수·비용·무게·설치시간은 원문 설계 문서 값이며, **열물성·풍하중 계수는 시뮬레이션용 가정값**입니다(앱에 '가정값'으로 표시). 실제 적용 전 KDS 41 12 00 및 제조사 데이터로 검증이 필요합니다.
- 설계안 E의 문서 표기 "50장"은 3×6 m 지붕·65 kg과 맞지 않아 1.4×0.6 m 패널 20장(4×5)으로 모델링했습니다.
- 모델 세부와 한계: [`docs/physics.md`](docs/physics.md)

## 로컬 실행 · 개발

```bash
npm install
npm run dev      # http://localhost:8765
npm test         # 물리 검증 + 모듈 통합 스모크 테스트
npm run build    # dist/ (GitHub Pages용 정적 사이트)
```

`main` 브랜치에 푸시하면 GitHub Actions가 테스트 → 빌드 → Pages 배포를 자동으로 실행합니다.

구성: three.js 0.160 (ES 모듈, 빌드 도구 없음), Chart.js 4.4. 모듈 간 인터페이스는 [`docs/CONTRACT.md`](docs/CONTRACT.md)에 정리되어 있습니다.

| 경로 | 내용 |
|---|---|
| `js/config.js` | 치수·설계안 데이터(단일 출처) |
| `js/container.js`, `js/environment.js` | 컨테이너 모델, 하늘·조명·현장 |
| `js/designs/` | 설계안 A–E 3D 모델 |
| `js/physics/` | 태양 위치·일사, 열 모델, 풍하중 |
| `js/viz/` | 그늘 레이캐스팅, 열지도, 기류, 태양광선, 애니메이션 |
| `js/ui/`, `index.html` | 컨트롤·대시보드 |
